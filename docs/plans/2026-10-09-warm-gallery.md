# 暖光艺术馆版实施计划

> 使用 writing-plans 制订、executing-plans 逐项执行，单代理；用户已确认暖光艺术馆风格，并指定以第一版视频为基础。沿用当前项目工作区，保留两份历史 MP4，不自动提交或推送。

**目标：** 基于首版完整树冠的镜头与 15 秒时序，交付更有空间层次、手工材质和柔和光影的 1080×1920 MP4。

**架构：** 恢复首版竖屏完整树冠镜头（历史会话中核实原始参数），保留近景参数作为可回归的独立取景配置。独立 gallery 模块管理暖色侧光、无缝弧形背景和接触阴影；独立 textile 模块管理可复现的纺织纹理。既有绝对时间生长和认证逐帧导出链路继续使用，不添加云端服务、依赖或全屏特效。

**技术栈：** Three.js / TypeScript / Vitest、Chrome DevTools MCP、FFmpeg / FFprobe。

---

## 已确认边界

- 基础文件：`artifacts/woven-life-mobile-15s-1080x1920.mp4`，不是 close 近景版。
- 时长 15 秒、24 fps、9:16、无声；保持 0–4 / 4–10 / 10–13 / 13–15 秒四段节奏。
- 恢复首版竖屏 10 秒 `[13,11.2,22.5]`、13 秒 `[8.8,10.6,23.8]`、14.4 秒 `[10.7,10.5,25.3]`，目标点 `[0,5.2,0]`，FOV 72°。开场和横屏不变。
- 保留完整树形及彩色纤维，不把造型改成写实植物，不加霓虹、满屏粒子、文字水印或背景音乐。
- 美化优先级：光影与无缝背景 > 纤维/织物/圆片材质区分 > 生长前沿层次。树冠几何与叶片数量不变。

## 任务 1：规格与回归测试

文件：`app/src/timeline.ts`、`app/film.json`、`tests/timeline.test.ts`、`tests/gallery.test.ts`、`tests/textile.test.ts`。

1. 先添加首版关键机位精确回归、近景可选回归、完整树冠逐帧投影边界测试。
2. 添加纹理确定性/无随机闪烁/有效颜色通道测试；画廊背景几何有限、灯光方向与阴影配置测试。
3. 运行 `npm test` 观察新增测试预期失败。
4. 实现新模块，改共享文件名为 `woven-life-mobile-gallery-15s-1080x1920.mp4`；重跑测试。

## 任务 2：画廊灯光与织物材质

文件：新增 `app/src/gallery.ts`、`app/src/textile.ts`，修改 `app/src/stage.ts`、`app/src/tree.ts`。

1. 搭建象牙暖灰无缝弧形背景：大面积侧上主光、低强度冷中性补光、暖色轮廓光，避免所有表面同样亮。
2. 使用支持现有生长 depth shader 的柔和阴影，加入仅限底座的淡接触阴影；不使用会忽略生长裁剪的法线覆盖 SSAO。
3. 纤维与叶片采用不同 UV 尺度的程序织纹、轻微粗糙度起伏及柔和布料 sheen；树皮保留粗糙纹理，装饰片使用克制的暖金反射。
4. 加大纤维错峰但仍在原动作窗口完成；不重排叶片、圆片及分镜完成时间。
5. 检查资源释放，避免纹理/背景/灯光 shadow render target 泄漏。
6. `npm test`、`npm run build`、`git diff --check`。

## 任务 3：实际浏览器审美检查

1. 核实并复用开发服务；Chrome DevTools `list_pages` 后创建本任务独立上下文，所有工具指定所属 pageId。
2. 检查页面快照、关键帧截图：2 / 4 / 7 / 10 / 11.5 / 13 / 14.958 秒。
3. 对照第一版同时间 MP4 抽帧检查颜色、完整树冠、阴影、纹理和细节。以实际截图为准调整，不仅看测试。
4. 验证反向定位后重复帧一致，控制台无渲染错误；检查默认造型研究和横屏仍可使用。

## 任务 4：成片与交付

1. `npm run build`、`npm run export:video`；后台隐藏启动，仅监听 127.0.0.1，保存 PID/端口/日志。
2. 在本任务导出页渲染 360 个确定时间帧。完成后复制为 artifacts 顶层新文件，禁止覆盖原始/近景 MP4。
3. FFprobe 验证编码、尺寸、帧数、帧率和时长，FFmpeg 全量解码；抽帧联系表及原版/新版对照图。
4. 移动视口检验播放、seek、ended 与媒体错误，明确不是手机真机实测。
5. 更新 README 和 `docs/verification/2026-10-09-warm-gallery.md`，仅清理本任务导出进程、页面及匹配凭据。
