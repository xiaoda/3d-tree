# 织生：Three.js 艺术树开发方案

> 执行方式：按 writing-plans / executing-plans 工作流逐项实施，在静态造型验收后进入完整动画阶段；不使用子代理。本目录尚未初始化 Git，不自行创建仓库或提交。

**目标：** 根据 `photos/` 内用户拍摄的艺术装置照片，制作保留彩色纤维树干、巨型雕塑叶片、金黄色圆片装饰的三维树，并最终输出横屏艺术短片。

**架构：** Three.js 负责程序化建模、材质、灯光和画面渲染；轻量本地预览界面负责视角、播放、参考图和静帧导出。造型配置与建模代码分离，使用固定随机种子；动画由绝对时间驱动，为后续逐帧视频输出预留统一入口。

**技术栈：** TypeScript、Three.js、Vite、Vitest；浏览器验证优先使用 Chrome DevTools MCP。正式视频阶段评估本地 FFmpeg 编码，不预先假定工具已安装。

---

## 1. 已确认的创作方向

- 画幅：横屏 16:9；首版静帧输出 1920 × 1080。
- 风格：手工艺术生命化，而非写实植物、霓虹特效树或普通随机树。
- 技术：先用 Three.js，不使用 Blender，不上传照片到第三方生成服务。
- 最终形式：约 20 秒艺术短片；浏览器只是创作、预览与输出工具。
- 首版场景：暖灰／米白展陈空间，柔和接触阴影，以金黄、赭橙、苔绿为主，少量粉紫。
- 单张照片无法确定背面、遮挡结构、真实尺寸和完整树冠；相应部分为同风格设计补全，不宣称精确重建。

## 2. 首个里程碑：静态造型与材质原型

### 本轮实施范围

1. 连续的扭转树干、底部根系、向外延伸的主要分枝。
2. 表面粗细变化的彩色线束，树皮和纤维具有不同的粗糙度与色彩。
3. 有实际厚度和弯曲的巨型叶片、立体叶脉、局部金黄色薄圆片装饰。
4. 人工安排主要叶片与树冠层次；仅次要细节使用有种子的随机分布。
5. 16:9 画布，完整树形、仰视参考、材质近景三个镜头，支持自由旋转检查。
6. 可暂停的轻微呼吸预览；不是最终编织生长动画。
7. 参考照片对照、隐藏界面、PNG 静帧导出、加载失败提示。
8. 单元测试、构建检查、真实浏览器快照和截图验证。

### 暂不实施

- 完整 20 秒生长分镜、声音设计、MP4 最终交付。
- 布料／绳线物理模拟、多用户功能、后端账号系统。
- 自动上传、公网发布、超写实光线追踪、承诺实时 4K。

## 3. 造型实现

### 树干与根系

- 中心路径使用可控样条，沿路径生成半径变化、非圆截面的网格。
- 根部放大并生成向地面延伸的根脊，不使用独立圆柱粗暴拼接。
- 主要分枝从树干内部开始，使用逐渐变细的截面，并用表面线束弱化交汇边界。
- 树皮凹凸由程序纹理与几何共同表现；不直接把带游客与展厅背景的照片贴在模型上。

### 表面纤维

- 曲线沿树干表面纵向流动，加入不均匀扭转和局部绕结。
- 主要线束生成细管几何；次级细节交给程序化凹凸纹理。
- 同材质曲线合并几何，控制绘制调用；不为每根线单独建立高成本材质。

### 巨型叶片

- 使用橡叶式裂片、长叶、圆叶等少量母版轮廓。
- 网格有前后表面与侧边，沿长度方向弯曲，叶脉独立成型。
- 每片叶子的根部、方向、大小、翻转角、配色由配置控制。
- 主要叶片之间保留空间，不使用球形树冠和随机树叶云。

### 圆片装饰

- 使用低面数薄片实例化，在叶片有效范围内采样，跟随叶面位置和法线。
- 尺寸、颜色、倾角小幅变化；固定种子保证截图与后续动画可重现。
- 近景保留实体起伏，不使用发光点代替手工圆片。

## 4. 模块与数据流

```text
app/src/config.ts                 造型配色、叶片布局、相机预设
app/src/procedural.ts             有种子随机、叶形采样、截面计算
app/src/geometry.ts               树干／曲线／有厚度叶片几何
app/src/tree.ts                   模型装配、纤维、叶脉、装饰
app/src/stage.ts                  灯光、地面、相机、渲染、时间入口
app/src/main.ts                   控件、参考图、导出、异常处理
app/src/style.css                 克制的展陈式预览界面
scripts/dev-server.mjs            仅本地预览及运行信息记录
tests/*.test.ts                   稳定性、几何、时间驱动测试
artifacts/                       验证截图与静帧（不对外提供目录访问）
logs/                            本任务服务日志、PID、实际端口
```

数据流：`配置 + 固定种子 → 模型`；`时间 t → 叶片姿态 → 渲染`。

浏览器预览和导出共用同一场景。预留 `window.treeStudio.renderAt(t)`，要求相同时间得到相同姿态，不能累积上一帧误差。更改相机或导出分辨率后必须正确恢复交互状态。

## 5. 分步实施与验收

### 任务 1：初始化与纯函数测试

**新增：** `package.json`、`tsconfig.json`、`vite.config.ts`、`app/index.html`、`tests/procedural.test.ts`、`app/src/procedural.ts`。

1. 写固定种子随机可重复、输出范围正确、叶片轮廓闭合端点测试。
2. 运行 `npm test`，确认缺少实现时失败。
3. 实现纯函数，再运行测试通过。
4. 依赖安装使用锁文件；不使用远程 CDN 运行时依赖。

### 任务 2：建模与几何检查

**新增：** `app/src/config.ts`、`app/src/geometry.ts`、`app/src/tree.ts`、`tests/geometry.test.ts`。

1. 写几何坐标／法线有限、索引合法、包围盒非空、有厚度叶片测试。
2. 实现树干、根部、纤维与叶片母版，运行测试。
3. 添加手工布置的树冠与薄圆片装饰。
4. 对合并几何／实例化设置正确包围盒，避免视锥裁剪误隐藏。

### 任务 3：场景与预览

**新增：** `app/src/stage.ts`、`app/src/main.ts`、`app/src/style.css`、`scripts/dev-server.mjs`。

1. 建立暖灰背景、地面与柔和阴影、16:9 渲染区域。
2. 实现镜头切换、旋转检查、呼吸播放／暂停、照片对照和导出。
3. 默认完整树形静态画面，运动由用户主动启用；适配减少动态效果偏好。
4. 错误时显示明确提示，不让黑屏冒充加载完成。
5. 执行 `npm run build`，要求 TypeScript 检查和打包通过。

### 任务 4：本地验证与交付

1. 隐藏启动本任务服务，监听 `127.0.0.1`，使用系统分配的空闲端口。
2. 标准输出／错误写入 `logs/`，记录 PID、工作目录、实际端口；验证 HTTP 响应。
3. Chrome DevTools MCP 先 `list_pages`，再为本任务新建独立上下文和页面。
4. 检查快照、实际截图、控制台错误、各镜头与播放状态、窄屏布局。
5. 查看截图后修改遮挡、构图、材质或灯光问题，不仅以“构建通过”验收。
6. 保存至少一张完整树形静帧；核验导出图片尺寸及长宽比。
7. 更新 README 与本方案执行记录，提供本地 URL、已完成功能和已知限制。

## 6. 后续动画里程碑（静态方向确认后）

- 0–4 秒：根部纤维特写，线束向上延伸。
- 4–10 秒：主体显露、分枝成形、叶片错峰舒展。
- 10–16 秒：圆片沿叶面聚合，侧光强调手工质感。
- 16–20 秒：拉到完整构图，保留轻微呼吸并停顿。
- 统一时间轴、镜头轨迹与种子；以 `t = frameIndex / 24` 渲染 480 帧，再编码视频。
- 正式视频须检查帧数、分辨率、首尾画面、闪烁和穿插；录屏只作为快速草稿。

## 7. 关键取舍与风险

| 决策／风险 | 应对 |
| --- | --- |
| 不引入 Blender | 造型参数都在代码中，复杂雕刻精度有限；优先关键轮廓与中景观感 |
| 单图导致不可见结构不确定 | 明确设计补全，参考视角与完整视角分别验收 |
| 大量细管和圆片成本高 | 合并同材质几何、实例化圆片、限制默认像素比，实测后调整 |
| 分枝接缝／叶片穿插 | 交界处包裹、调整布局，并用多个镜头检查 |
| 程序化模型太规整 | 控制局部不对称、粗细变化、非均匀配色，重要位置不随机 |
| Three.js 阴影出现条纹 | 限定阴影视锥，调整偏移和分辨率，近景截图确认 |
| 浏览器不支持渲染或上下文丢失 | 明确错误提示；不掩盖失败、不自动更改系统设置 |
| 本地服务泄露无关目录 | 只开放 app 及必要依赖，不服务用户主目录、日志、源照片目录 |
