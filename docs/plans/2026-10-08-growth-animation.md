# 织生：20 秒生长动画实施计划

> 使用 writing-plans 制订、executing-plans 逐项实施；本次由同一代理完成，不使用子代理。用户已确认第二版造型满意，并批准进入动画开发。

**目标：** 交付可播放、暂停、反向拖动和逐帧定位的 20 秒生长动画预览，保持第二版最终模型不变。

**架构：** 纯函数时间轴计算阶段、枝叶进度和镜头。木质与合并纤维携带沿路径的出生时间属性，用共享时间 uniform 驱动显示及阴影；叶片以叶柄为支点错峰舒展；圆片实例沿叶面顺序从近处聚合到原始位置。所有状态只依赖绝对时间，不依赖上一帧。

**技术栈：** 现有 TypeScript / Three.js / Vite / Vitest；Chrome DevTools MCP 独立页面验证，不添加运行时依赖。

---

## 设计与范围

- 采用分部件路径显露，而非整树缩放／淡入；不引入重型绳线物理模拟，避免破坏已确认的造型。
- 0–4 秒根部纤维与向上生长；4–10 秒分枝成形、叶片错峰舒展；10–16 秒圆片聚合；16–20 秒完整构图、呼吸与收尾停留。
- 默认仍显示已确认的完整静态树，用户主动进入动画；无自动播放。导演镜头和自由观察可切换。
- 保留原静态镜头、参考照片、纯净预览和 1080p PNG 导出；增加 24 fps 前后逐帧、重播、时间滑块与四个分镜入口。
- 本批为动画预览验收，不提前交付最终 MP4、音乐或公网部署。已发现本地 FFmpeg / FFprobe，下一批可用 `t = frameIndex / 24` 输出 480 帧并编码。

## 风险与处理

- 着色器显露可能产生开放截面；实际实现中已为树干、根脊及枝条补充随前沿移动的实体封口。细纤维端点仍为风格化显露，而非真实绳线仿真。
- 必须同步阴影材质，不能让尚未长出的树投射完整树影。
- 圆片超过一万个，采用实例矩阵且只在聚合期更新，保留性能实测，不承诺所有设备实时帧率。
- 不能把单元测试通过当作视觉验收；需实际截图检查根部起笔、枝叶连接及动画中途的遮挡。

技术核对：本机已安装 Three.js 源码与 [Material 官方文档](https://threejs.org/docs/pages/Material.html)、[Mesh 官方文档](https://threejs.org/docs/pages/Mesh.html) 中的材质编译扩展／自定义阴影材质接口。
